@bugsnag/browserlite example

This page demonstrates @bugsnag/browserlite, a minimal build of the Bugsnag browser notifier. By default it only bundles error/rejection capture - everything else (breadcrumbs, sessions, device metadata, etc.) is opt-in via the plugins config option, so you only ship the code you actually use.
